# Send service: interview starter

The starter for the backend coding interview, one branch per level. Clone
the branch your interviewer named, at the tag they gave you:

    git clone -b senior https://github.com/Newton-Capital/backend-interview-starter.git
    git clone -b mid https://github.com/Newton-Capital/backend-interview-starter.git

The README on that branch is the brief; everything you need is there.
