# Send service: interview starter

The starter for the backend coding interview, one branch per level: `senior`
and `mid`. This `main` branch holds only this page; the work is on the branch
your interviewer named. Clone that branch, at the tag they gave you if they
gave one:

    git clone -b senior https://github.com/Newton-Capital/backend-interview-starter.git
    git clone -b mid https://github.com/Newton-Capital/backend-interview-starter.git
    git clone -b v1.0.0 https://github.com/Newton-Capital/backend-interview-starter.git   # a tag works the same way

If you have already cloned the repository and are on `main`, switch instead:

    git switch senior      # or: git switch mid

The README on that branch is the brief; everything you need is there.
